## M22 图谱横坐标自适应缩放

### 现状（已核实）
- `views/widgets/plot_widget.py`
  - `plot_data()`（L143-171）：每次绘图 `relim()` + `autoscale_view()` —— matplotlib 默认 5% 边距，5°–150° 数据得到约 0–152° 显示，且**无法通过鼠标滚轮缩放**（matplotlib toolbar 的 zoom-to-rect 对连续谱线交互差）。
  - `set_x_range(x_min, x_max)`（L280）存在但**无任何调用方**。
  - `phase_view.py:693` `_flash_peak` 硬编码 `set_xlim(t±8)`。
- 无滚轮/拖动平移绑定（`mpl_connect('scroll_event')` 未注册）。

### 目标
1. 首屏横坐标**贴合数据实际 2θ 范围**（边距 ≤1%，可配）。
2. **滚轮缩放 + 中键/左键拖动平移**（以鼠标位置为中心缩放，这是 Match!/Origin 的默认交互）。
3. 重置视图（toolbar Home / 重置按钮）回到"数据范围"而非固定 0–150。
4. 多数据集叠加时取 2θ 并集；切换 Y 轴刻度模式（linear/log/sqrt）不影响 X 视图。

### 原子任务
| # | 文件 | 改动 |
|---|---|---|
| M22-1 | `views/widgets/plot_widget.py` | 新增 `fit_x_to_data(margin_ratio: float = 0.01) -> None`：取 `self._data_list` 全部 two_theta min/max，加 margin，`set_xlim`；`_data_list` 空时 no-op |
| M22-2 | 同上 | `plot_data()` / `clear_plot()` 后调 `fit_x_to_data()` 替换裸 `relim/autoscale`（Y 仍走 `_y_scale.set_mode(refit=True)` 老路） |
| M22-3 | 同上 | 新增 `_install_x_interaction()`：`scroll_event` → 以 `event.xdata` 为中心 ±15%/格缩放（clamp 到数据范围外扩 20%）；`button_press_event` 左键拖动 → X 平移（与峰点击检测兼容：位移 <3px 视为点击） |
| M22-4 | 同上 | `reset_view()` 改为 `fit_x_to_data()` + Y refit；保存 `_home_xlim` 供 toolbar Home 使用（monkeypatch `self._toolbar.home` 或子类化） |
| M22-5 | `views/phase_view.py:693` | `_flash_peak` 的 `t±8` 改为 t±（数据宽度 × 0.05），并记录"闪前视图"支持恢复 |

### 边界
- 单数据集 / 空数据 / 全零强度 / NaN 点
- 与 `y_scale.py` 的交互（Y 缩放独立，不得串扰）
- log 模式下 `xdata` 变换（mpl 内部坐标是数据坐标，直接可用）
- `NavigationToolbar2QT.home` 的默认行为是回到 `_nav_stack` 底——需确保 fit 后入栈

### 验收
- [ ] 加载 5°–150° 数据，首屏 X ≈ 4.9°–150.5°
- [ ] 滚轮 10 格后 Home → 精确回到首屏范围
- [ ] 拖动平移越界被 clamp；峰点击（<3px）仍触发 `peak_clicked`
- [ ] 新增单测 `tests/test_v015_x_interaction.py`（合成 XRDData，断言 xlim）

## M25 外部精修程序集成（GSAS2 / MAUD / FullProf）

> 动机（用户原话）：内置精修结果 Rwp/GOF 过大、不理想；点击按钮直接用本机已装的
> 专业程序精修。FullProf 为**新集成**（Match! 集成的就是它，本机 `C:\FullProf_Suite` 已确认：
> `fp2k.exe` 控制台引擎、`wfp2k.exe`、`WinPLOTR-2006.exe`、`CIFs_to_PCR.exe`、`edpcr.exe` 齐备）。

### 现状（已核实）

两条路径并存（用户说"不适用本程序集成的精修功能"）：

2. **启动按钮**：点击后把「当前数据 + 勾选物相」导出为外部程序所需输入，拉起外部进程；

## 风险登记

| 风险 | 等级 | 缓解 |
|---|---|---|
| FullProf .pcr 格式坑多（Jbt/Pat 段语义） | 高 | 首选 CIFs_to_PCR.exe 转换；拿 Match!4 导出的 pcr 做 golden file 对照 |

| 外部程序拉起后无法回读（GSAS2 GUI 模式） | 中 | 降级语义明确：能回读的回读，不能的只做"导出+拉起" |
| 布局重构动 restoreState | 中 | 升 `_WINDOW_STATE_VERSION`（红线条款 #9） |
| 右键菜单与既有槽位冲突 | 低 | 统一 handler 挂 QMenu，先查现有 contextMenuPolicy |
