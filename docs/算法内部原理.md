## 1. 内置 Rietveld 引擎总览

核心代码: `src/polyxrd/services/rietveld_refiner.py` → `_refine_builtin()`

```
实验谱 y_obs(2θ)
  ├── 背景估计 (median 中值滤波) ──────────────────── y_exp = y_obs − bg
  ├── 参考峰收集 (每物相 (hkl, 2θ, I_ref) 列表)
  ├── 智能权重初值 (按实验谱在参考峰位的强度比例)
  ├── 多起点 least_squares (4 起点, trf, 边界约束)
  │     参数 x = [w₁..wₙ, fwhm, eta, scale, zero_shift, U, V, W]
  │     每个起点独立收敛 → 显式计算 wR → 取最优
  ├── 稀疏邻域 wR 抛光 (~135 点网格)
  └── 快速路径: 无 Caglioti 3 起点快检, wR ≤ 55% 直接返回 (v8)
```

### 1.1 峰形模型 (pseudo-Voigt)

```
PV(Δ) = η·G(Δ) + (1−η)·L(Δ)
G(Δ) = exp(−Δ²/2σ²),  σ = FWHM / (2√(2ln2))
L(Δ) = γ²/(Δ²+γ²),   γ = FWHM/2
```

### 1.2 Caglioti 峰宽函数 (2θ 依赖)

```
FWHM(2θ) = √(U·tan²θ + V·tanθ + W)
```

- U/V/W 作为拟合参数（边界 U∈[−0.05,0.20], V∈[−0.10,0.10], W∈[1e-4,4.0]）
- U=V=0 时退化为固定 FWHM=√W，与旧模型一致
- 实测收益：4-1 试样 wR 65.69% → 64.74%（宽角峰 FWHM 固定值估计不足）

### 1.3 wR 定义

```
wR = √( Σᵢ(yᵢ − ycᵢ)² / Σᵢ yᵢ² ) × 100%
```

**关键教训**: L2 损失（Σr²）的极小值 ≠ wR 的极小值（分母 Σy² 固定但
residual 权重感受不同）。因此多起点与抛光每个候选都**显式计算 wR 选优**，
不能只看 least_squares 的 cost。

## 2. 背景估计：为什么 median 完胜 snip

| 方法 | 实现 | 问题 |
|---|---|---|
| snip | 滑动最小 + 均匀滤波 (n//20 窗) | 窄窗削峰 → 假残差；宽窗背景漂移 |
| **median** | `scipy.signal.medfilt(k=51)` | 稳健、不削峰，**直接降 5-6pt wR** 🔑 |

低 2θ 空气散射背景估计是 wR 偏高的**第一根因**。除非重新整定窗口，
不要换回 snip。

## 3. 多起点与抛光的踩坑记录

| 尝试 | 结果 | 教训 |
|---|---|---|
| 参考峰全局归一化 (max I=100) | 2-1 wR 57%→93% ❌ | scale×weight 耦合 + wR 分母不一致，**不要归一化** |
| residual × √(1/y) 加权 | fwhm 撞上界 0.5 ❌ | 背景区 y≈0 点被 1/y 放大主导 L2；只可对峰区加权 |
| soft_l1 loss | 2-1 解跳到 98/2 退化 ❌ | 简化引擎 L2 更稳；换 loss 必须看 residual 分布 |
| 只调 weight_upper (30→200) | 4-1 完全无效 | 参数边界不是杠杆，**峰形模型/背景方法才是** |
| 3⁸ 全网格抛光 (6561 点) | 单样 ≥5 min ❌ | 稀疏子空间 (~135 点) 效果几乎一样 |

## 4. V0.9.1 性能优化 (P2)

### 4.1 瓶颈定位

单次 2-1 精修 144s，其中 `_compute_spectrum_from_ref` 占 99.3%
（5210 次调用 × ~40ms）。调用次数来源：

```
least_squares 非收敛起点 4 × max_nfev=1200 ≈ 4800 次  ← 主要浪费
局部抛光 ~135 次 + 初始化 ~10 次
```

实测：获胜起点仅需 ~55 nfev；跑满 1200 的起点全是无效局部极小。

### 4.2 三项优化

1. **快速路径** (`wR_threshold`，默认 55%)：
   先跑 `use_caglioti=False, n_starts=3` 快检，wR ≤ 55% 直接返回；
   否则启 Caglioti 精细模式，最终返回两者中 wR 更低者。
   **返回结果只会更好不会变差**（择优逻辑），2-1 类样品直接省掉 Caglioti 全程。
2. **单起点收敛上限** `max_nfev_per_start`（默认 min(20×max_cycles, 400)）：
   1200 → 400，4-1 wR 完全不变。
3. **分块向量化** `_compute_spectrum_from_ref`：
   - 每块 16 峰，临时数组 512KB 驻留 CPU 缓存
   - 参考峰按物相连续排列，列切片累加（避免布尔掩码 fancy-indexing）
   - 数学等价（差异 <1e-13），数值已验证
   - 注：全矩阵向量化 (n_points×n_peaks) 实测反而比逐峰循环慢 2x
     （临时数组超缓存，内存带宽瓶颈），勿改回

### 4.3 验收结果

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 3 项 wR 验收测试总耗时 | 11-12 min | **4 min 10 s (2.8x)** |
| 2-1 wR | 51.46% | 51.79% (快速路径, <55% ✓) |
| 4-1 wR | 64.74% | 64.74% (不变 ✓) |
| 可重复性 | 0% | 0% ✓ |

## 5. Le Bail 晶胞精修 (P4, V0.9.1 新增)

`refine_le_bail()` —— 无需原子占位/结构强度模型，仅精修晶胞几何。

### 5.1 算法

1. hkl∈[−3,3]³ → `_calc_peak_positions()` 计算允许衍射峰位
2. **匹配门控**：计算峰位处观测强度 ≥ 5% 全谱最大才参与提取，其余置零
3. 经典 Le Bail 迭代提取积分强度：
   `Iⱼ ← Σ(y_obs−others)·PVⱼ / (1.05·ΣPVⱼ²)`，上限 2×窗口观测最大
4. Rwp = √(Σ(y_obs−y_calc)²/Σy_obs²)，网格扫描晶胞尺度因子取最优

### 5.2 匹配门控为什么必须

无门控时，错配峰窗口落在真实峰尾部 → Σpv²→0 → 强度爆炸（"尾峰窃取"），
Rwp 对峰位失敏，晶胞扫描完全失效。门控后错配 Rwp≈100%、正确 Rwp<5%，
判别度极大。单元测试见 `tests/test_le_bail.py`（3 项，2.5s）。

## 6. 物相识别要点

- **FOM** = 相对偏差归一化 + 未匹配峰惩罚，`combined_score = FOM × (1−0.3·match_ratio) × (1−0.1·intensity_score)`
- **纯金属惩罚 ×1.5**：Fe/Ni/Cu 等参考峰少（2-3 条），易偶然误匹配
- **自动扩展 exclude**：must∪maybe 的补集一律排除（比手写 exclude 重要）
- **同化学式去重**：α/γ/θ-Al₂O₃ 等多型只留 coverage/FOM 最高一条
- **COD 无机物库检索** (V0.9.1)：Hanawalt d-I 预筛（主峰原则 + 强度加权召回）
  → top-50 候选 → 统一 FOM 评分，与内置库同一口径
