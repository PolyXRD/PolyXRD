# PolyXRD 5 分钟上手 —— 以 4-1 四相混合试样为例

> 适用版本: V0.9.1+ · 测试数据: `D:\TEMP\test_xrd\txt\4-1.txt`
> 4-1 试样真实组成: ZnO (Zincite) / Al₂O₃ (Corundum) / CaF₂ (Fluorite) / Mg(OH)₂ (Brucite) 四相混合

---

## 0. 启动

双击 `PolyXRD.exe`（安装版）或运行 `python -m polyxrd.main`（源码版）。

---

## 1. 装载数据 (30 秒)

**文件 → 打开** → 选择 `4-1.txt`。

- 数据视图自动绘制衍射谱（约 7251 个数据点，2θ 5-80°）
- 状态栏显示"数据加载完成: 7251 个数据点"

## 2. 预处理 (30 秒)

在数据视图预处理面板依次执行：

| 步骤 | 推荐参数 | 说明 |
|---|---|---|
| 背景扣除 | SNIP-40 或 中值滤波 | 低 2θ 空气散射背景是 wR 偏高第一根因 |
| 平滑 | Savitzky-Golay w=11 p=3 | 保留峰高，勿过度平滑 |
| 归一化 | Max | 峰高归一到 100 |

## 3. 峰检测 (30 秒)

- 峰检测面板: 自动阈值（SNR ≥ 2）→ **搜索**
- 4-1 试样应检出 ~20-40 个峰

## 4. 物相检索 (1 分钟)

物相分析页签：

1. **数据库源** 下拉框选择：
   - `内置库 (118 物相)` —— 最快，日常快检
   - `COD 无机物库 (71,199)` —— 需挂载外挂库，Hanawalt d-I 预筛
   - `COD 全库 (113,223)` —— 本地 CIF 索引检索
   - `内置+COD全库合并` —— 结果合并排序
2. （可选）**元素过滤 (周期表)**: 必须 Zn/Al/Ca/F/Mg/O → 大幅减少误命中
3. 点击 **传统 Search/Match** 或 **Profile Fitting (推荐)**

4-1 试样应命中: Zincite (ZnO)、Corundum (Al₂O₃)、Fluorite (CaF₂)、Brucite (Mg(OH)₂)。
点击候选物相可在谱图上查看 **绿色实线（已匹配峰）/ 红色虚线（未匹配峰）**。

## 5. 多物相确认 + 精修 (1-2 分钟)

1. 依次点击候选列表中的 4 个正确物相 → **选中物相 →**
2. 确认后自动切换到 **结构精修** 页签
3. 精修引擎选择:
   - `builtin` —— 内置简化引擎（v8: 中值背景 + Caglioti 峰宽 + 多起点 + 快速路径）
   - GSAS-II / powerxrd —— 需另行安装引擎
4. 点击 **开始精修**

验收参考（内置引擎）:

```
4-1 wR ≈ 64.7% (四相均 >0.5%)
2-1 两相样 wR ≈ 51.8% (ZnO:CaCO₃ ≈ 60:40)
```

> 内置引擎 wR 偏高的原因与改进路线见《算法内部原理.md》第 5 节。

## 6. 导出 (30 秒)

- **文件 → 保存项目** (.polyxrd): 全参数 JSON 序列化，可完全回放
- **导出**: 峰列表 CSV / PNG+SVG 图像 / 多物相报告 PDF

## 常见问题

**Q: COD 数据库怎么挂载？**
文件 → 导入外部数据库 → 选择 `COD_inorganics.sqlite`（无机物库）或 `cod_index.sqlite`（全库）。
路径持久化于 `~/.polyxrd/user_db_paths.json`，支持运行时热切换。

**Q: 识别结果全是纯金属？**
使用元素过滤，或升级到 V0.9.0+（内置纯金属惩罚 ×1.5 + 组合中纯金属 ≤20% 防御）。

**Q: 精修后某相含量为 0？**
该相可能为误命中。检查其参考峰覆盖率（点击候选查看红/绿峰），覆盖率 <55% 的相建议剔除。
