## 2. 版本亮点 (What's New in 0.8.21)

### 2.1 核心架构升级
- **程序 / 数据库分离发布**: PolyXRD 主程序作为标准 Windows 安装包发布,COD 无机物库作为独立外挂 zip 发布,两者独立分发、独立升级,避免单发布包体积超 1 GB。
- **数据库导入接口**: 新增 `文件 → 导入外部数据库 → COD 无机物库` 菜单,支持用户一键挂载外部 SQLite 数据库(持久化保存到 `%LOCALAPPDATA%\PolyXRD\`),下次启动自动加载。
- **动态数据库路径**: `AppConfig.cod_db_path` 支持三重优先级 — **用户导入路径 > %LOCALAPPDATA%\PolyXRD\databases\ > 程序内置 cod_data/**。

### 2.2 品牌与合规
- 项目全局清除了第三方商标字样,数据库统一命名为 **COD 无机物库 (20260821 版本)** 并覆盖源码、UI 文案、翻译文件、发布说明与文件名。
- 数据库表列 `match_ref_id` 重命名为 `ref_id`,脚本 `match_*.py` 重命名为 `build_cod_sqlite.py` / `package_cod_db.py`,下载启动脚本重命名为 `start_cod_download.ps1`。

### 2.3 版本元数据
- `src/polyxrd/config.py` 与 `pyproject.toml` 同步版本号 `0.8.21`。
- PyInstaller 产物 `PolyXRD.exe` 版本信息 `0.8.21.0` (FileVersion/ProductVersion),安装程序版本匹配。

## 3. 完整功能清单

### 3.1 XRD 数据处理流水线
| 模块 | 功能 |
|---|---|
| 数据加载 | `.xrdml` (PANalytical), `.raw` (Bruker binary), `.txt/.csv` (两列/多列 2θ-I), `.prf` (GSAS), 批量合并 |
| 波长支持 | Cu Kα (1.5406 Å) 主路,支持 Mo / Co / Cr / Fe / Ag / W / Au / Ga / Mn / Ni Kα |

| 平滑 | Savitzky-Golay (窗口 5~31, 2~5 阶), FFT 低通, Whittaker-Eilers |

## 4. 安装指南

### 4.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
|---|---|---|
| 操作系统 | Windows 10 21H2 x64 / Windows 11 x64 | Windows 11 23H2 x64 |
| CPU | 双核 1.5 GHz | 四核 3.0 GHz+ |
| 内存 | 4 GB RAM | 8 GB+ RAM (pymatgen/精修时更流畅) |
| 磁盘空间 | **1.3 GB** (主程序 955 MB + 数据库 260 MB) | 2 GB+ (批量数据处理留足余量) |
| 显示 | 1280×720 | 1920×1080 或更高 (HiDPI 已适配) |
| .NET / VC++ | 不需要 (Inno Setup 自带,PyInstaller 打包了完整 VC Redist 依赖) | — |

### 4.2 第一步: 安装主程序

> 若旧版 PolyXRD 正在运行,请先关闭。

1. 双击 `PolyXRD-Setup-v0.8.21.exe`,若出现 UAC 提示,点击"是"。
2. 许可协议 → 勾选"I accept the agreement" → Next。
3. 选择安装目录: 默认 `C:\Program Files\PolyXRD\` (需要管理员权限) → Next。
4. 勾选附加图标:
   - □ Create a desktop shortcut (桌面快捷方式,可选)
   - □ Create a start menu shortcut (开始菜单,可选)
5. 点击 **Install**,等待解压 955 MB 文件 (30~90 秒,视磁盘速度)。
6. 安装完成 → 勾选"Launch PolyXRD" → Finish。首次启动约 3~8 秒 (Qt6 + matplotlib 初始化)。

> **从旧版本升级**: 直接在旧版安装路径上覆盖安装即可,用户配置 (注册表 HKCU\Software\PolyXRD) 与项目文件不会被覆盖。如需卸载旧版,可在 Windows 设置 → 应用 → PolyXRD 卸载。

### 4.3 第二步: 挂载 COD 无机物数据库 (两种方式任选)

PolyXRD 0.8.21 默认不带数据库。您需要独立下载 **PolyXRD_COD_Inorganics_v0.8.21.zip**。

#### 方式 A · 一键安装脚本 (推荐 Windows 用户)
```
1. 解压 PolyXRD_COD_Inorganics_v0.8.21.zip 到任意目录
2. 双击 install_COD_database.bat → 弹出黑窗 → 按 Y 回车
3. 脚本会自动:
   - 复制 COD_inorganics.sqlite → %LOCALAPPDATA%\PolyXRD\databases\COD_inorganics.sqlite
   - 写入 HKCU\Software\PolyXRD\cod_db_path 注册表
4. 启动 PolyXRD,在 "设置 → 数据源" 可见 "COD 无机物库 (71,199 phases)" 字样 → 完成
```

#### 方式 B · 图形界面菜单导入 (跨平台通用)
```
1. 解压 PolyXRD_COD_Inorganics_v0.8.21.zip,记住 COD_inorganics.sqlite 的路径
2. 启动 PolyXRD → 顶部菜单: 文件 → 导入外部数据库 → COD 无机物库
3. 文件选择对话框中定位 COD_inorganics.sqlite → 打开
4. 对话框提示 "导入成功 71,199 物相" → 确定
5. 该路径会被持久化保存,重启无需重复导入
```

#### 数据库加载校验
打开 **物相检索** 面板,在化学式框输入 `SiO2`,点击"搜索":
- 若立即返回 30+ 条石英/柯石英等候选,说明数据库已正确挂载。
- 若提示"COD 数据库未加载",请重新执行 4.3 步骤,或前往 **设置 → 数据源** 手动输入路径。

### 4.4 卸载
```
设置 → 应用 → 已安装的应用 → PolyXRD 0.8.21 → 卸载
  或:
开始菜单 → PolyXRD → 卸载 PolyXRD
```
> 卸载时会删除程序目录 (955 MB),**不会删除**用户的 COD 数据库与项目文件。  
> 若要彻底清除用户数据,请一并删除 `%LOCALAPPDATA%\PolyXRD\` 目录。

## 7. 已知问题与限制

1. **多物相排序与干扰相处理**: 对 5 相以上、峰强重叠严重的样品,Top 候选可能将弱相 (含量 < 5%) 排在更后。建议用户在"必须元素"面板中提前勾选已知元素以提升准确率。
2. **PyInstaller 首次冷启动**: 首次运行需 3~8 秒 (pymatgen / matplotlib 数据加载),后续启动 1~2 秒。属 Python 打包常规现象,非 Bug。
3. **安装包体积 (240.9 MB)**: 因包含完整 PySide6 (Qt6 22 DLL)、pymatgen (spglib/网络协议栈)、scipy 数学库,无法进一步显著压缩。如需更轻量版本,可切换 onefile 模式 (单 exe 运行时需解压到 Temp,启动更慢)。
4. **macOS / Linux 原生包**: V0.8.21 仅发布 Windows x64 版本。macOS / Linux 用户可从源码运行 (`pip install -e .` + `python -m polyxrd.main`)。
