# PolyXRD 物相分析功能路线图与模块拆分（对标 Match!）

> **本文用途**：把「对标 Match! 的粉末 XRD 物相鉴定/半定量/定量」拆成可独立实现的小模块、小方法。
> 每个方法给足：文件位置、函数签名、输入输出、算法步骤、边界与错误处理、验收断言、依赖。
> 目标是：后续可以把任意一个"叶子方法"单独交给一个低智商模型去实现，而不需要它理解全局。

---

## 0. 对标结论与总原则

Match! 的完整工作流（来自 Help 目录 / Tips / FAQ / 视频）是：

```
导入数据 → 原始数据处理(trim/平滑/Kα2剥离/背景/峰搜索/轮廓拟合)
        → 仪器校正(零点/样品位移/内标)
        → 候选检索(元素/名称/密度等约束 + 预设)
        → 搜索-匹配(FoM) → 候选评估 → 多相迭代识别(残差峰)
        → 半定量 RIR / 定量 Rietveld(择优取向/DoC/内标)
        → 报告导出 → (进阶) 指标化/结构求解/晶粒尺寸
```

**我们的差异化路线（避免商业授权）**：

| Match! 依赖 | PolyXRD 替代方案 | 状态 |
|---|---|---|
| ICDD PDF 数据库 | COD 开源库（无机物 71,199 + 全库 113,223，均已接入） | ✅ 已接入 |
| FullProf (Rietveld) | 自研 builtin Rietveld + GSAS-II 桥 + Le Bail | ✅ 已接入 |
| Diamond (结构可视化) | 自研轻量 3D 视图 | ⏸ 暂缓（M17，最后再考虑） |
| Treor/Dicvol (指标化) | 外部调用或自研 | ⏸ 暂缓（M15，最后再考虑） |

**工程原则**（沿用项目约定）：
1. 算法全部放 `src/polyxrd/services/`，纯函数、可单测；模型放 `models/`；UI 走 `viewmodels/`+`views/`（MVVM）。
2. 每个方法配套 pytest；算法改动必须有"输入→期望输出"的断言。
3. 数据库文件（sqlite/tar.xz）不进 git。
4. 提交信息用「更新代码修正: …」风格；不在提交信息里出现软件全名。

### M03 原始数据处理管线 (P0) ✅ 已实现 (Sprint 2)

文件：`src/polyxrd/services/raw_processing.py` **(新)**。

> 状态：✅ `trim`(包装 XRDData.crop + 校验) / `smooth_savitzky_golay`(SG, 温和
> reps=1) / `strip_kalpha2`(Rachinger 逐点前向递归去卷积, 间距随 2θ 变化,
> 用已校正值插值, 负值截 0) / `increase_resolution`(CubicSpline, factor 1~4)。
> 测试 `tests/test_raw_processing_m03.py` 11 项全过。验证要点: Kα2 剥离后与
> "纯 Kα1 谱"最大残差 <25% 主峰 (近似插值), 主峰≈Kα1 原高。

| 方法 | 签名 | 算法步骤 | 边界 |
|---|---|---|---|
| `trim` | `(xrd, t_min, t_max) -> XRDData` | 1) 找 t_min/t_max 在 2θ 中的最近索引 2) 切片 | 范围超出时截到端点；t_min>=t_max 抛错 |
| `smooth_savitzky_golay` | `(xrd, window, polyorder, reps=1) -> XRDData` | 1) 校验 window 为奇、>polyorder 2) 对强度做 SG 卷积 3) reps 次重复 | window 过大吞弱峰（tips 强调）；默认 reps=1 温和 |
| `strip_kalpha2` | `(xrd, wavelength1, wavelength2, ratio) -> XRDData` | Rachinger 迭代去卷积：对每个 2θ，`y'(2θ)=y(2θ)-ratio*y(2θ-Δ2θ)`，其中 `Δ2θ=2·asin(λ2/λ1·sin θ)-2θ`，从高角向低角或迭代 | 起始区不扣除；强度为负截 0；无 Kα2 波长参数时用 Cu 默认(1.5406/1.5444, 比 2.0) |
| `increase_resolution` | `(xrd, factor) -> XRDData` | 1) 用三次样条/线性在 2θ 上插值 factor 倍 2) 生成等步长新轴 | factor 过大噪声"固化"(tips)；限制 factor≤4 并告警 |

**验收**：合成含 Kα1/Kα2 双峰的谱，`strip_kalpha2` 后双峰变单峰、峰位回到 Kα1；`smooth` 前后主峰积分面积相对差 <1%。

### M08 仪器校正 (P0) ✅ 已实现 (Sprint 1)

文件：`src/polyxrd/services/calibration.py` **(新)**。

> 状态：✅ `zero_point_shift`(轴平移)/`specimen_displacement_offset|shift`
> (BB 反射/透射两种几何, 逐点依 cosθ 校正)/`estimate_from_histogram`
> (Δ2θ 直方图众数, Peak/Phase/dict 输入均可)/`calibrate_to_internal_standard`。
> 符号约定: error = obs−true, 校正 = 观测减 error (与 Rietveld 模型内加项方向相反)。
> 测试 `tests/test_calibration_m08.py` 9 项全过。

| 方法 | 签名 | 说明 |
|---|---|---|
| `zero_point_shift` | `(xrd, dz) -> XRDData` | 常数 2θ 偏移校正（`tt_new = tt - dz`） |
| `specimen_displacement_shift` | `(xrd, displacement, radius, mode) -> XRDData` | Δ2θ 依几何模型：Bragg-Brentano 平样 `Δ2θ = -(2s/R)cosθ`(弧度)；反射/透射不同符号 |
| `estimate_from_histogram` | `(obs_peaks, ref_peaks, tol) -> float` | 对每条实测峰找最近参考峰算 Δ2θ，做直方图取众数 → 建议校正值（tips：用直方图辅助判断） |
