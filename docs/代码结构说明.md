## 总览

PolyXRD 采用 **MVVM 分层架构**：`views/`（PySide6 UI）↔ `viewmodels/`（状态与命令）
↔ `services/`（纯算法，无 Qt 依赖，可独立单元测试）+ `models/`（数据模型）。
入口 `main.py`；多语言在 `i18n/`；外部智能体接口在 `mcp_server/`。

## 分层说明

| 层 | 位置 | 职责 | 约束 |
|---|---|---|---|
| 视图 | `src/polyxrd/views/` | 窗口/面板/交互，PySide6 控件 | 不写算法；文案走 i18n 三语言键 |
| 视图模型 | `src/polyxrd/viewmodels/` | 状态、命令、错误码编排 | 不直接触碰 Qt 控件细节 |
| 服务 | `src/polyxrd/services/` | 全部核心算法（检索/FoM/精修/转换/数据库） | **不依赖 Qt**，可独立单测 |
| 模型 | `src/polyxrd/models/` | 数据结构（图谱/峰/物相/FoM 结果/精修参数） | 纯数据 |
| 脚本 | `scripts/` | 构建/发布/基准/库维护 | 交付性脚本入库 |

## 关键链路

1. **数据 → 峰**：`data_loader` → `data_preprocessor`（背景/平滑/Kα2 剥离）→ `peak_finder`
2. **峰 → 物相**：`phase_identifier`（三库检索 + 元素过滤）→ `foam`（FoM 打分）→ 组合选择（B&B 联合覆盖）
3. **物相 → 结构**：`phase_structure_resolver`（CIF 回填）→ `rietveld_refiner`（内置 Le Bail 级 / GSAS-II / FullProf / MAUD）
4. **结果 → 交付**：`report` / `export_service` / `project_service`（`.polyxrd` 项目）
