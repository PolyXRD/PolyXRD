### W00 新增指标自检测试（预期先红）

- 目的：把"指标公式对不对"变成可自动断言。
- 文件：新增 `tests/test_metrics_selfcheck.py`。
- 内容：只测 `RietveldRefiner._calc_profile_metrics` 与 `_calc_wR`（纯函数）。6 条断言：
  1. Rwp 标尺不变：`y→c*y`（`y_calc` 同步放大）时 Rwp 变化 < 1e-6。
  2. Rexp（poisson，P=0）解析值：`100*sqrt(N/sum(max(y,1)))`，误差 < 0.1%。
  3. GOF 自洽：模型=真模型 + Poisson 噪声（poirier `sigma2`）时 `GOF ∈ [0.8, 1.3]`。
  4. Rexp 标尺律：`y→c*y` 时 `Rexp → Rexp/sqrt(c)`（相对误差 < 1%）。
  5. Rp 公式：`100*sum(abs(y_obs-y_calc))/sum(y_obs)`，用已知小数组精确核对。
  6. `chi2_red == GOF**2`（±1e-9）。
- 边界：不改 `_calc_profile_metrics` 本身；本步对当前代码，断言 1/3/5 应通过、2/4/6 应失败（预期）。
- 验证：`.\venv\Scripts\python.exe -m pytest tests\test_metrics_selfcheck.py -q` → 记录哪几条失败（M1 后它们应转绿）。

## M1 · 指标修复（P0 核心，先做）

### W02 重写 `_calc_profile_metrics`

- 文件：`src/polyxrd/services/rietveld_refiner.py` 的 `_calc_profile_metrics`（约 2122 行）。
- 改动：签名改为 `_calc_profile_metrics(observed, simulated, sigma2=None, n_params=0, legacy_weight=None)`。逻辑：

```
observed = np.asarray(observed, float)
simulated = np.asarray(simulated, float)
if sigma2 is not None:
    w = 1.0 / np.maximum(np.asarray(sigma2, float), 1e-12)
elif legacy_weight is not None:
    w = np.asarray(legacy_weight, float)
else:
    w = np.ones_like(observed)
N = int(observed.size)
P = max(0, int(n_params))
n_free = max(1, N - P)
den = float(np.sum(w * observed ** 2))
num = float(np.sum(w * (observed - simulated) ** 2))
rwp = 100.0 * np.sqrt(num / den) if den > 0 else 100.0
rexp = 100.0 * np.sqrt(n_free / den) if den > 0 else 100.0
gof = rwp / rexp if rexp > 0 else 0.0
rp_den = float(np.sum(observed))
rp = 100.0 * np.sum(np.abs(observed - simulated)) / rp_den if rp_den > 0 else 100.0
return {"Rwp": rwp, "Rexp": rexp, "Rp": rp, "Rb": rp,
        "GOF": gof, "chi2": num, "chi2_red": gof ** 2}
```

- 边界：保留旧键 `Rwp/Rexp/Rb/GOF`（不删），新增 `Rp/chi2/chi2_red`；`den==0` 返回 100/0 不除零；`sigma2` 必须是**未归一化**方差。

## M3 · 峰形面积归一（P1 最高性价比）

### W11 伪 Voigt 面积归一

- 文件：`src/polyxrd/services/phase_display.py` 的 `spectrum_from_refs`（全矩阵 + 窗口化两处都要改）。
- 原理：Rietveld 要求积分强度 ∝ `m·LP·|F|²·S`，与峰宽、η 无关；当前高斯/洛伦兹都是"峰高=1"，面积随 FWHM 变。
- 公式（`σ = FWHM/(2√(2ln2))`、`γ = FWHM/2`、`Δ = x - x0`）：

```
高斯   G = (1/(σ·√(2π))) · exp(-0.5·(Δ/σ)²)
洛伦兹 L = (γ/π) / (Δ² + γ²)
伪Voigt PV = η·G + (1-η)·L        # ∫PV = 1，与 FWHM、η 无关
```

- 落点：现有 `gauss = exp(...)`、`lorentz = γ²/(Δ²+γ²)` 之后分别乘 `1/(σ·√(2π))` 与 `γ/π`；纯 `gaussian`/`lorentzian` 分支用对应面积归一式。
- 边界：不改 `scale`/`weights`/参数布局；`init_scale_est` 用同一函数自校准，无需手调；不引入新依赖。
- 验证：新增 `tests/test_peak_shape_area.py`：单相单峰、`cutoff_fwhm=100`、细网格，断言 `sim.sum()*step ≈ I`（±1%），且改 FWHM/η 后不变。
- 回滚：只还原本文件两处乘系数。
