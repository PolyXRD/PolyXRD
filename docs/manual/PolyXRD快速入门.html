PolyXRD 快速入门 · v0.15.0 · 5 分钟上手

本指南帮助你在最短时间内完成一次完整的 XRD 物相分析流程：装载数据 → 扣背景 → 找峰 → 物相鉴定 → 结构精修 → 导出报告。详细功能与原理请参阅《PolyXRD 使用手册》。

启动：双击桌面 PolyXRD 图标，或运行安装目录下 bin/PolyXRD.exe。首次启动软件会自动完成初始化，界面为中文。

第 1 步 · 装载数据

数据页 → 「装载文件」，选择 .xy / .txt / .dat / .rdf 等一维衍射数据（本项目自带测试数据：E:\TEMP\test_xrd\txt\）。

装载后主窗口左侧显示衍射谱，右侧为文件信息（波长、步长、起止角）。确认 波长 X 射线靶材（默认 Cu Kα1, λ=1.5406 Å）与实际实验一致，可在「波长」下拉中切换或手动输入。

图 1　数据装载后主界面

第 2 步 · 扣背景与找峰

物相页 → 「处理」：先 SNIP 扣背景，再以二阶导数法自动找峰。

找峰参数一般保持默认（信噪比阈值 3、最小峰间距 0.5°）。黑色圆点为扣除背景后的观测点，红色曲线为拟合峰形，绿色竖线标记峰位。

图 2　自动找峰结果

第 3 步 · 物相鉴定

物相页 → 「鉴定」→ 数据源选「内置库」→ 开始鉴定。软件用峰位对内置 COD 无机物相库检索，按 FoM（品质因子）排序。

结果列表给出候选物相的化学式、空间群、晶胞参数与匹配度。点选某行即在谱图上叠加该物相的理论峰位（竖线），点击「采纳」将其加入物相列表。可逐条采纳多个物相直至谱线基本对齐。

图 3　物相鉴定与理论峰位叠加

第 4 步 · 结构精修（Rietveld）

精修页 → 引擎选「内置 (builtin)」→ 「开始精修」。也可选 GSAS-II / MAUD / FullProf 外部引擎做全谱精修。

内置引擎为保守精修：自动依次放开标度因子 → 背景多项式 → 晶胞参数 → 峰形 (U, V, W)，每步检查收敛。精修完成后显示 Rwp（拟合优度指标，越低越好）、逐相含量表与拟合差值曲线。

图 4　精修完成：Rwp、物相含量与外置引擎状态（绿色=可用）
说明：内置引擎不精修原子坐标（物相库不含完整结构），因此 wR 在 50%~90% 属正常水平；需要发布级结果请用 GSAS-II / MAUD / FullProf 外部引擎。外部程序需在「数据库 → 外部程序」中配置路径，或点击「检测」自动定位。

第 5 步 · 导出报告

报告页 → 「生成报告」，一键导出 HTML 分析报告，包含谱图（含拟合线与差值线）、物相列表、含量表与精修指标。

常见问题速查

现象处理
图谱加载后没有峰检查波长与起始角设置；数据含表头时勾选「跳过文件头」
鉴定结果为空检查是否扣了背景；峰太少（<5 个）时放宽信噪比阈值
精修不收敛 / Rwp 不降先只精修标度+背景；确认采纳的物相确实存在，多余的物相先删除
外部引擎红灯「数据库 → 外部程序」中手动指定程序路径后「验证」
想改物相的晶胞/峰形精修页双击物相行进入参数表，勾选要放开的参数
更多内容：多步精修向导（分步放开参数）、数据库管理、批量处理、MAUD/GSAS-II/FullProf 外部精修的详细操作与 Rietveld 原理，请见《PolyXRD 使用手册 v0.15.0》。
