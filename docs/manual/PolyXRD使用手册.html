第 1 章　软件概述

1.1 PolyXRD 是什么

PolyXRD 是一款 Windows 桌面 X 射线粉末衍射（XRD）数据分析软件，覆盖从原始谱图到物相鉴定、再到结构精修与报告输出的完整离线工作流：

数据加载 → 谱图预处理 → 峰检测 → 物相检索匹配 → 勾选物相 → Rietveld 结构精修 → 结果报告

软件支持五类精修引擎（auto / builtin / gsas2 / maud / powerxrd），并可与外部专业程序 FullProf、GSAS-II、MAUD 联动；内置常用矿物库，并可外挂 COD 无机物库、COD 全库与 ICDD PDF-2 2004。

1.2 主要功能

模块功能
数据处理多格式加载（.xy/.xye/.txt/.csv/.dat/.mdi/.raw/.xrdml/.brml 等）、扣背景（SNIP/线性/多项式）、平滑（Savitzky-Golay）、Kα2 剥离、归一化、角度裁剪；谱图格式转换（8 种格式互转）
物相分析自动峰检测（含肩峰识别）、多库检索匹配（FoM 打分排序）、元素过滤、物相勾选、CIF 导出、COD 在线检索
结构精修快速精修 + 分步精修向导双路径；builtin/gsas2/maud/powerxrd/auto 五引擎；外部 FullProf 一键批处理精修
报告 / 项目Rietveld 报告预览与导出（json/pdf）、项目保存与恢复（含物相勾选集）
设计取向：PolyXRD 的目标是用一条龙的离线工作流覆盖常规实验室分析需求；与 JADE、FullProf Suite、MAUD、GSAS-II 等专业软件可互相配合使用。

2.1 三种发行形态

2.2 安装包（Setup）

双击 PolyXRD-Setup-v2.0.1.exe 启动安装向导。v2.0.1 起向导提供简体中文 / 繁體中文 / English / 日本語 四种语言，系统语言为中文时会自动选中中文。

向导流程：选择语言 → 选择安装位置（可选「为所有用户安装」）→ 选择附加任务（桌面图标）→ 安装 → 完成。

安装位置建议：默认路径为当前用户目录（%LOCALAPPDATA%\Programs\PolyXRD），无需管理员权限。若你要装到 D:\Program Files\... 等受保护目录，请在向导中选择「为所有用户安装」（v2.0.1 起提供安装模式选择），否则可能因权限不足而无法写入目标目录。
关于安装耗时：安装包约 250 MB，解压后约 1.1 GB、上万个文件。在「正在解压文件」阶段进度条推进较慢，实测约 4～5 分钟（机械硬盘更久），属正常现象，请耐心等待、勿中途关闭——这通常就是「以为安装卡住了」的原因。
安装异常时就这样查：v2.0.1 起安装程序会自动写日志到 %TEMP%\Setup Log <日期> #NNN.txt。若安装失败，请把该日志末尾数十行提供给我们定位。若该目录下根本没有当天的日志，通常说明安装程序根本没跑起来（多为被杀毒软件 / 安全策略拦截）。

卸载：开始菜单 →「卸载 PolyXRD」，或在「设置 → 应用」中卸载。

2.3 便携版（Portable）——启动稳健性

最重要的一条：必须先「完整解压」，再运行。请不要在压缩包内直接双击 PolyXRD.exe——Windows 会把文件解到临时只读目录（路径含随机字符），Qt 的插件（platform/ 图像格式等）会加载失败，典型表现就是「窗口一闪就退出」。请右键压缩包 →「全部解压缩」，解到一个普通可写目录（如 D:\PolyXRD）后再运行。

解压后的目录结构：

文件 / 目录作用
PolyXRD.exe主程序

安全模式启动.bat强制软件渲染（软件 OpenGL）启动，用于规避显卡驱动导致的崩溃

启动自愈机制（v2.0.1 新增）

部分 Windows 11 / 显卡驱动组合下，主窗口在显示瞬间会触发 Qt 原生崩溃（这类崩溃发生在窗口显示时，Python 层无法捕获，表现就是「一闪即退」）。v2.0.1 引入了跨启动自愈：

① 程序启动时会先写下「本次启动尚不健康」的状态；若窗口成功存活数秒，则标记为「健康」。
② 若上一次启动未能存活（仍是「不健康」状态），本次启动会自动切换到软件渲染（等价于安全模式），通常即可正常打开；日志里会出现 auto safe-render 字样。
③ 若自愈后仍异常，请直接使用 安全模式启动.bat。

手动重置：执行 PolyXRD.exe --reset-render 可清除自愈状态（回到硬件渲染），一般无需使用。
诊断开关：PolyXRD.exe --diagnose 打印运行环境与依赖信息；PolyXRD.exe --safe-render 本次强制软件渲染（不改动持久状态）。
启动日志：位于 %USERPROFILE%\.polyxrd\logs\startup-<日期>.log。正常启动应能看到 MainWindow OK 与 shown ... visible=True；若缺失，说明主窗口未成功显示，请把该日志提供给我们。

2.4 数据库挂载（重要）

主程序不内置大型衍射数据库——三个库各自独立打包、各自下载、各自挂载，只装其中一个也能正常使用，不必凑齐安装。首次使用物相检索前，请通过工具栏 「数据库管理」 挂载至少一个衍射数据库：

① 点击工具栏「数据库」图标打开数据库管理器；② 对需要的库点「导入…」，选择对应的 .sqlite 文件（官方数据库包下载后解压即可得到）；③ 显示「已挂载」即成功，路径会被记住，下次启动自动加载。

注意：PDF2-2004 数据库为 ICDD 版权数据，请确认已获得正版授权后再挂载使用；该库不随软件分发。
未挂载任何库时：仍可使用内置的 118 种常见矿物 / 物相进行检索与演示。

4.1 加载数据

点击工具栏「打开」或菜单 文件 → 打开数据，选择谱图文件。支持的格式：

.xy / .xye / .txt / .csv / .dat两列/三列文本（2θ-强度 或 2θ-强度-误差），自由分隔符，自动跳过 # / ! 注释行

4.2 预处理步骤（建议顺序）

步骤入口作用与原理
① 扣背景工具栏「扣背景」/ 左侧面板选方法去除空气散射、荧光、样品台散射等缓变背景。SNIP 算法对晶面密集、背景起伏复杂的谱最稳健；线性/多项式适合背景平缓的谱
② 平滑左侧面板「平滑方法」Savitzky-Golay 卷积在去噪的同时保留峰形（窗口宽度 11 点为常用起点；窗口过大会压低峰高）
③ 剥 Kα2工具栏「剥 Kα2」Cu 靶 Kα1/Kα2 双线使每条衍射峰成对出现。Rachinger 法按强度比 Kα2/Kα1≈0.5 逐点剥除 Kα2 贡献
④ 归一化 / 裁剪左侧面板强度归一到 0-100 或最大值 100；裁掉仪器盲区（如 <15° 或 >100° 低信噪比区段）

第 5 章　物相分析

5.1 峰检测

切到「物相分析」标签，点击工具栏「峰检测」（或左侧面板调阈值后自动运行）。默认以相对高度 5%、最小间距 0.5°、突出度 1% 自动找峰；勾选「高精度（容忍肩峰+亚像素）」可识别重叠肩峰并细化峰位。

峰检测是检索匹配的输入。峰太多（噪声被误检）→ 提高最小高度/突出度；峰太少（弱峰漏检）→ 降低阈值或提高灵敏度。

5.2 检索匹配（Search/Match）

点击「传统 Search/Match」或左侧「开始识别」。软件将检出峰位（d-I 列表）与数据库中的标准卡片比对，按匹配度 FoM（Figure of Merit）排序输出候选物相：

FoM = w₁ · (峰位匹配率) + w₂ · (强度相关性) + w₃ · (强峰命中率)　—　逐峰在容差角（默认 ±0.15°）内配对打分

5.3 数据库选择

第 6 章　结构精修

6.1 Rietveld 精修原理（30 秒版）

Rietveld 法不用单个峰的积分强度，而是用结构模型逐点计算整张衍射谱并与实测谱做最小二乘拟合：

ycalc(2θ) = ybg(2θ) + Σ相 S相 · Σhkl Ihkl · φ(2θ − 2θhkl)
Ihkl ∝ |Fhkl|² · mhkl · LP(θ) · e−B·sin²θ/λ²　（结构因子×多重性×洛伦兹-偏振×温度因子）
目标：min Σ wi(yobs,i − ycalc,i)²,　wi = 1/σ²(yi).

可精修的量包括：标度因子（→物相含量）、晶胞参数（→峰位）、峰形（Caglioti U/V/W、η）、零点偏移、背景多项式，以及原子坐标与占位。拟合质量用 R 因子衡量：

Rwp = √( Σ wi(yobs,i − ycalc,i)² / Σ wiy²obs,i )　　GOF (S) = Rwp / Rexp
合格参考：常规实验室数据 Rwp<15%、GOF≈1~3 视为良好。builtin 内置引擎为快速峰形拟合（非完整 Rietveld），其 Rwp 明显偏高属预期，请用 gsas2 / maud / fullprof 出定量结论。

6.5 精修质量指标与评分（v2.0.0 重要更正）

v2.0.0 起，评价指标本身做了根因级修正——历史版本的 Rexp / GOF 因权重口径配置错误而没有物理意义（例如某些试样 Rexp 偏小上百倍、GOF 高达数百）。修正后：

指标含义
wR（加权 Rwp）加权轮廓 R，默认使用 Poisson 统计权重
Rexp期望 R，权重正确后才可解读（标准定义 w = 1/σ²）
GOF (S)Rwp/Rexp，理想值接近 1
Rp轮廓 R（Σ|Δy|/Σy，旧版曾误标为 "Rb"）
口径铁律（跨版本比较必读）：默认改为 Poisson 统计权重后，加权 wR 与旧版「单位权 wR」不可直接比较（同一拟合的加权值与未加权值可相差 8 个百分点以上）。跨版本 / 跨软件比较 wR 时务必声明口径。

质量分级（实验室粉末 XRD 口径，已统一为一套阈值）：<5 优秀 / <10 良好 / <15 一般 / <25 差 / ≥25 需改进。

若指标不可解读（例如所用引擎不回传必要方差信息），界面会明确显示「不可解读」，而不会给出一个看似漂亮的数字。

6.6 峰形、背景与峰位物理（v2.0.0 改进）

项说明
峰形面积归一峰形函数改为面积归一（∫PV = 1）。此前为「峰高归一」，会让积分强度随峰宽变化、η 不再是混合比；修正后峰宽参数才具备可解释性
背景进入拟合背景不再「开头估一次即冻结」，默认对背景做 Chebyshev 多项式抛光（6 阶），仅在更优时采纳
样品位移可精修样品位移（Δ2θ = −2s·cosθ），修正由样品偏心引起的峰位系统偏移
低角不对称（可选）split pseudo-Voigt，用于低角区轴向发散导致的峰形不对称（默认关闭，按需开启）
全晶胞参数模式（可选）由 a/b/c/α/β/γ 直接精修峰位（默认关闭，按需开启）
Kα2 双线检测自动判断数据中是否存在未剥离的 Kα2，命中则在结果提示条给出警告，提示先剥 Kα2 再精修

第 8 章　基本原理

8.1 Bragg 定律与衍射位置

2d·sinθ = n·λ

晶面间距 d 的晶面族在入射角 θ 处产生相长干涉。测得一系列 2θ 峰位、已知波长 λ，即可反推各晶面的 d 值序列——这是物相「指纹」比对的物理基础。

8.2 衍射强度

各 (hkl) 衍射的积分强度由结构因子 |Fhkl|²（原子种类与坐标决定）、多重性因子 m、洛伦兹-偏振因子 LP、温度因子 e−B·sin²θ/λ² 共同决定。因此强度分布是第二重指纹，也是 Rietveld 定量相分析的依据。

8.3 检索匹配 (Search/Match)

传统流程 = Hanawalt（以最强 3 峰的 d 值组合查索引）+ Fink（8 强峰）+ 逐峰容差匹配与强度相关打分。PolyXRD 对数据库预先计算 d-I 峰表并建立强峰索引，检索时先粗筛再精排（FoM），从而在十万级卡片上实现秒级响应。

8.4 背景与峰形

SNIP 背景算法：对谱反复做「LLS 求 minimum → clipping」的尺度递归，把快变峰「削」掉只留慢变背景，适合荧光/陡变背景。峰形用 pseudo-Voigt（Gaussian 与 Lorentzian 线性组合，混合系数 η）描述，并做面积归一；峰宽随角度的变化用 Caglioti 公式 FWHM² = U·tan²θ + V·tanθ + W。

第 9 章　常见问题（FAQ）

Q1：便携版双击后窗口一闪就退出？
按顺序排查：① 是否完整解压后运行（切勿在压缩包内直接运行——最常见原因）；② 改用目录内的 启动 PolyXRD.bat 启动；③ 若仍异常，改用 安全模式启动.bat（强制软件渲染）；④ v2.0.1 的跨启动自愈通常会在第二次启动时自动切到软件渲染并恢复正常；⑤ 查看 %USERPROFILE%\.polyxrd\logs\startup-<日期>.log 确认是否有 MainWindow OK / shown。

Q2：安装包中文界面 / 安装无法继续？
v2.0.1 起安装向导内置简体、繁體中文。若安装被「无法写入目标目录」卡住：请在向导中选择「为所有用户安装」（需要管理员权限），或改回默认安装位置。安装过程会自动写日志到 %TEMP%\Setup Log <日期> #NNN.txt，请提供该日志以便定位；若该目录下没有当天日志，通常是安装程序被杀软 / 安全策略拦截。

Q3：物相检索没有结果 / 结果很差？
按顺序检查：① 是否已挂载数据库（数据库管理器状态）；② 峰检测是否合理（过多/过少都会毁掉匹配）；③ 是否应开启元素过滤；④ 波长是否正确；⑤ 尝试换数据库（builtin → cod_inorganics → merged）。

Q4：builtin 精修 wR 很高？
builtin 是内置快速峰形拟合引擎，不计算结构因子，用于快速验证物相组合。定量结论请改用 gsas2 / maud / auto，或使用外部 FullProf 批处理精修。

Q5：wR 比上一版「变大」了？
v2.0.0 起默认启用 Poisson 统计权重，加权 wR 与旧版单位权口径不可直接比较；且历史版本的 Rexp/GOF 本身是错的（现已修正）。请以同一版本、同一口径下的前后对比为准。

Q6：外部程序状态灯是红色？
点该行「检测」自动探测；仍不行则「浏览…」手动指定（FullProf 选 fp2k.exe；GSAS-II 选其自带 python.exe；MAUD 选安装根目录或 jdk/bin/java.exe）。配置会持久化，重启后保留。

Q7：精修不收敛 / 发散？
常见原因：物相初始晶胞错误（换一张卡片或导入 CIF）；标度因子量级差太多（FullProf 路径已自动校准）；背景方法不当（改 SNIP）；数据噪声过大（先平滑 + 扣背景）；数据中 Kα2 未剥离（注意结果提示条的 Kα2 警告）。分步放开参数（先 scale+bg，再 cell，再峰形）比一次全放开稳健。

Q8：谱图 X 轴显示范围不对？
图谱自动收缩到数据范围；滚轮缩放、左键拖拽平移、工具栏 Home 复位。

Q9：外部精修后文件在哪里？
C:\Users\<用户名>\.polyxrd\external_runs\<程序_时间戳>\，内含 .dat/.pcr（FullProf 输入）、.sum/.out（结果）、导出的 .xy/.xye 与 CIF。

Q10：窗口布局乱了（工具栏挤在一边）？
窗口状态损坏时旧布局会被自动作废重建；也可删除 ~/.polyxrd 下的布局配置重置。
