第 1 章  软件概述

1.1 PolyXRD 是什么

PolyXRD 是一款Windows 桌面 X 射线粉末衍射（XRD）数据分析软件，覆盖从原始谱图到物相鉴定、再到结构精修与报告输出的完整工作流：

数据加载 → 谱图预处理 → 峰检测 → 物相检索匹配 → 勾选物相 → Rietveld 结构精修 → 结果报告

软件支持五类精修引擎（auto / builtin / gsas2 / maud / powerxrd），并可与外部专业程序 FullProf、GSAS-II、MAUD 联动；内置五套衍射数据库（内置矿物库、COD 无机物库、COD 全库、合并检索、ICDD PDF-2 2004）。

1.2 主要功能

模块功能
数据处理多格式加载（.xy/.xye/.txt/.csv/.dat/.brml 等）、扣背景（SNIP/线性/多项式）、平滑（Savitzky-Golay）、Kα2 剥离、归一化、角度裁剪、格式导出
物相分析自动峰检测（含肩峰识别）、多库检索匹配（FoM 打分排序）、元素过滤、物相勾选、CIF 导出、COD 在线检索
结构精修快速精修 + 分步精修向导双路径；builtin/gsas2/maud/powerxrd/auto 五引擎；外部 FullProf 一键批处理精修
报告/项目Rietveld 报告预览与导出（json/pdf）、项目保存与恢复（含物相勾选集）
设计取向：PolyXRD 的目标是用一条龙的离线工作流覆盖常规实验室分析需求；与 Match!、JADE、FullProf Suite、MAUD、GSAS-II 等专业软件可互相配合使用（本软件可直接生成/导出它们可读的数据与控制文件）。

图 4-1  加载数据后：谱图自动绘出，X 轴自适应收缩到数据范围

若加载后衍射峰位置整体偏移，请检查「波长」参数（默认 Cu Kα1 1.5406 Å）是否与实验条件一致；修改后重新加载。

4.2 预处理步骤（建议顺序）

步骤入口作用与原理
① 扣背景工具栏「扣背景」/ 左侧面板选方法去除空气散射、荧光、样品台散射等缓变背景。SNIP 算法（尺度递归最小化）对晶面密集、背景起伏复杂的谱最稳健；线性/多项式适合背景平缓的谱
② 平滑左侧面板「平滑方法」Savitzky-Golay 卷积在去噪的同时保留峰形（窗口宽度 11 点为常用起点；窗口过大会压低峰高）
③ 剥 Kα2工具栏「剥 Kα2」Cu 靶 Kα1/Kα2 双线使每条衍射峰成对出现。Rachinger 法按强度比 Kα2/Kα1≈0.5 逐点剥除 Kα2 贡献，使后续检索与精修基于单色峰位
④ 归一化 / 裁剪左侧面板强度归一到 0-100 或最大值 100；裁掉仪器盲区（如 <15° 或 >100° 低信噪比区段）

4.3 保存与导出

菜单 文件 → 保存/导出 可将处理后的谱保存为 .xy / .xye 等文本格式，供 FullProf、GSAS-II、MAUD 等外部程序直接读取。

第 5 章  物相分析

5.1 峰检测

切到「物相分析」标签，点击工具栏「峰检测」（或左侧面板调阈值后自动运行）。默认以相对高度 5%、最小间距 0.5°、突出度 1% 自动找峰；勾选「高精度（容忍肩峰+亚像素）」可识别重叠肩峰并细化峰位。

图 5-1  峰检测：竖标记为检出峰位，右侧参数可实时调节灵敏度

峰检测是检索匹配的输入。峰太多（噪声被误检）→ 提高最小高度/突出度；峰太少（弱峰漏检）→ 降低阈值或提高灵敏度。

5.2 检索匹配（Search/Match）

点击「传统 Search/Match」或左侧「开始识别」。软件将检出峰位（d-I 列表）与数据库中的标准卡片比对，按匹配度 FoM（Figure of Merit）排序输出候选物相：

FoM = w₁ · (峰位匹配率) + w₂ · (强度相关性) + w₃ · (强峰命中率)　—　逐峰在容差角（默认 ±0.15°）内配对打分

图 5-2  识别结果：左侧候选列表含匹配度/化学式/卡片号，谱图叠加标准峰位（竖线）

5.4 勾选物相与 CIF 导出

在候选列表勾选可信物相（可多选）。勾选集会实时同步到：

① 主窗口右侧「物相列表」停靠窗（v0.15 起默认空、由勾选驱动，右键可导出 CIF / 查看详情）；② 精修页右栏「已选物相」列表（同样支持右键导出 CIF）；③ 项目文件（保存/恢复随项目走）。

CIF 导出优先从本地 COD 目录读取全文，缺失时自动回退 COD 在线接口——导出的 CIF 可直接作为精修初始模型。

第 6 章  结构精修

6.1 Rietveld 精修原理（30 秒版）

Rietveld 法不用单个峰的积分强度，而是用结构模型逐点计算整张衍射谱并与实测谱做最小二乘拟合：

ycalc(2θ) = ybg(2θ) + Σ相 S相 · Σhkl Ihkl · φ(2θ − 2θhkl)
Ihkl ∝ |Fhkl|² · mhkl · LP(θ) · e−B·sin²θ/λ²　（结构因子×多重性×洛伦兹-偏振×温度因子）
目标：min Σ wi(yobs,i − ycalc,i)²,　wi = 1/σ²(yi).

可精修的量包括：标度因子（→物相含量）、晶胞参数（→峰位）、峰形（Caglioti U/V/W、η）、零点偏移、背景多项式，以及原子坐标与占位。拟合质量用 R 因子衡量：

Rwp = √( Σ wi(yobs,i − ycalc,i)² / Σ wiy²obs,i )　　GoF (S) = Rwp/Rexp
合格参考：常规实验室数据 Rwp<15%、GoF≈1~3 视为良好。builtin 内置引擎为快速峰形拟合（非完整 Rietveld），wR 在 50%~90% 属正常现象，请用 gsas2/maud/fullprof 出定量结论。

第 8 章  基本原理

8.1 Bragg 定律与衍射位置

2d·sinθ = n·λ

晶面间距 d 的晶面族在入射角 θ 处产生相长干涉。测得一系列 2θ 峰位、已知波长 λ，即可反推各晶面的 d 值序列——这是物相"指纹"比对的物理基础。

8.2 衍射强度

各 (hkl) 衍射的积分强度由结构因子 |Fhkl|²（原子种类与坐标决定）、多重性因子 m、洛伦兹-偏振因子 LP、温度因子 e−B·sin²θ/λ² 共同决定。因此强度分布是第二重指纹，也是 Rietveld 定量相分析的依据：物相质量分数正比于标度因子与 Rietveld 尺度方程。

8.3 检索匹配 (Search/Match)

传统流程 = Hanawalt（以最强 3 峰的 d 值组合查索引）+ Fink(8 强峰) + 逐峰容差匹配与强度相关打分。PolyXRD 对数据库预先计算 d-I 峰表并建立强峰索引，检索时先粗筛再精排（FoM），从而在十万级卡片上实现秒级响应。

8.4 背景与峰形

SNIP 背景算法：对谱反复做"LLS 求minimum→clipping"的尺度递归，把快变峰"削"掉只留慢变背景，适合荧光/陡变背景。峰形用 pseudo-Voigt（Gaussian 与 Lorentzian 线性组合，混合系数 η）描述；峰宽随角度的变化用 Caglioti 公式 FWHM² = U·tan²θ + V·tanθ + W。

第 9 章  常见问题（FAQ）

Q1：物相检索没有结果/结果很差？
按顺序检查：① 是否已挂载数据库（数据库管理器状态灯）；② 峰检测是否合理（过多/过少都会毁掉匹配）；③ 是否应开启元素过滤；④ 波长是否正确；⑤ 尝试换数据库（builtin → cod_inorganics → merged）。

Q2：builtin 精修 wR 高达 70~90%？
正常。builtin 是内置快速峰形拟合引擎，不计算结构因子，用于快速验证物相组合。定量结论请改用 gsas2 / maud / auto，或使用外部 FullProf 批处理精修。

Q3：外部程序状态灯是红色？
点该行「检测」自动探测；仍不行则「浏览…」手动指定（FullProf 选 fp2k.exe；GSAS-II 选其自带 python.exe；MAUD 选安装根目录或 jdk/bin/java.exe）。配置会持久化，重启后保留。

Q4：精修不收敛/发散？
常见原因：物相初始晶胞错误（换一张卡片或导入 CIF）；标度因子量级差太多（FullProf 路径已自动校准，其他引擎可先跑 builtin 验证）；背景方法不当（改 SNIP）；数据噪声过大（先平滑+扣背景）。分步放开参数（先 scale+bg，再 cell，再峰形）比一次全放开稳健。

Q5：谱图 X 轴显示范围不对？
v0.15 起图谱自动收缩到数据范围；滚轮缩放、左键拖拽平移、工具栏 Home 复位。

Q6：外部精修后文件在哪里？
C:\Users\<用户名>\.polyxrd\external_runs\<程序_时间戳>\，内含 .dat/.pcr（FullProf 输入）、.sum/.out（结果）、导出的 .xy/.xye 与 CIF。

Q7：窗口布局乱了（工具栏挤在一边）？
窗口状态损坏时旧布局会被自动作废重建（v0.15 起状态版本 v3）；也可删除 ~/.polyxrd 下的布局配置重置。

Q8：GUI 双击没反应？
查看 ~/.polyxrd/logs/startup-*.log；确认出现 MainWindow OK 与 shown。图标资源统一使用 PNG（启动稳定性规避措施）。
