## 一、四态元素过滤

### 语义（已按用户定义实现）

记 **S** = 物相元素集合，**P/H/M/E** = 必有/含有/可能/没有 的元素集合：

| 类别 | 键名 | 判定式 | 含义 |
|---|---|---|---|
| 必有 | `must_have` | `P ⊆ S` | **全部必含 (AND)** |
| 含有 | `must` | `S ∩ H ≠ ∅` | 物相由 H 构成，至少含其中一个 |
| 可能 | `maybe` | 无强制条件 | 仅放宽允许池；**H 为空时代行 H 之职** |
| 没有 | `exclude` | `S ∩ E = ∅` | 含任一即淘汰 |

补充规则：

- **未勾选元素默认并入 E**（闭环，等价 `S ⊆ P∪H∪M`），**仅当 P∪H∪M 非空时启用**
- 三者全空 = 全库搜索；**只勾「没有」= 开放世界**（仅排除这些元素）
- **勾了必有时不再要求至少含一个含有**（纯金属 Mg 仍可作为候选）
- 重叠优先级：必有 > 含有 > 可能 > 没有

### 用户示例自检（全部通过）

| 输入 | 结果 |
|---|---|
| 含有{Mg,Ca,C,O} | MgO / CaO / CaCO₃ / MgCO₃ / CaMgCO₃ ✅；ZnO、CaSO₄ 被排除 ✅ |
| 必有{Mg} + 含有{Ca,C,O} | MgO / MgCO₃ / CaMgCO₃ ✅；纯 Mg 也可 ✅；CaCO₃ 排除 ✅ |
| 必有{Mg,Ca,C,O} | 仅 CaMgCO₃ ✅ |
| 含有{Al,O} + 可能{H} | Al₂O₃ / Al / Al(OH)₃ ✅ |
| 含有{Al,O}（不勾 H） | Al(OH)₃ 被默认排除 ✅ |

### 实现变更

- 判定收敛为**单一纯函数** `utils/formula_parser.elements_match_filter`，
  内置库 / COD 库 / Profile Fitting **三条路径统一调用**，删除了原先两套互不一致的写法
- 新增 `normalize_element_filter`（旧工程文件的 `must` 键自动映射到「含有」）
- 修复：`profile_fitting` 原先只在勾了「必须」或「不含」时才过滤 → 单独勾「可能」时完全失效
- 修复：COD 路径原先只勾「没有」时会**排除全部候选**（`allowed` 为空集导致子集判定失败）
- UI：周期表改为四态循环（无 → 必有 → 含有 → 可能 → 没有），新增
  **「轻元素设为含有 (O,C,H,N,S)」** 按钮，摘要栏显式提示「未勾选 N 种元素默认按没有排除」

## 二、匹配因子（FoM）重构

### 三点结构性修正

| # | 问题（旧口径） | 修正 |
|---|---|---|
| 1 | 每条参考峰各自就近吸附，**多条参考峰可命中同一条实验峰** → 峰多的密集物相被系统性高估 | **一一对应互斥匹配**（按 \|Δ2θ\| 升序贪心分配） |
| 2 | 归一化用 `Σ2θ` → 高角度相、多峰相**天然占优**，与匹配好坏无关 | 改用 `Σw` 归一，`w = 0.3 + 0.7·I/Imax`（强峰加权） |
| 3 | 无特异性约束；强度一致性用 `min/max` 比（对弱峰极不稳定） | 新增**未解释实验峰惩罚** + **匹配对强度余弦**（尺度无关） |

```
score = (bad + 0.30 · 未解释比) · (1 − 0.20 · 强度余弦)      bad ∈ [0, 2]
bad   = [Σ_命中 w·(|Δ2θ|/tol) + Σ_漏检 w] / Σ_all w
```

置信度分档收敛到 `models/fom.confidence_from_score`：`<0.15` 极好 / `<0.40` 良好 /
`<0.70` 一般 / 其余可能不匹配。`phase_identifier._match_phase_fom` 改为直接委托
`foam.compute_fom`，删除了重复实现。

### COD 排序口径变更

旧口径是字典序 `main_peak_match → top_precision → 加权召回 → 召回 → FOM`。
`main_peak_match` 是 **0/1 二值**——多相样品里只有主物相能拿 1，**其余真物相被整体压后**。
改为加权混合：

```
rank_score = 0.3 · Hanawalt复合 + 0.7 · (1 − clip(fom / 1.2, 0, 1))
Hanawalt复合 = 0.40·main_peak_match + 0.30·top_precision
             + 0.20·intensity_weighted_top_recall + 0.10·top_recall
```

### 基准结果（13 试样 / COD 无机物库 / 生产默认池 `prefilter_limit=100`）

预期物相在候选列表中的位次命中率（按化学式 + 名称比对）：

| 排序口径 | Top-1 | Top-5 | Top-10 |
|---|---|---|---|
| 旧（Hanawalt 字典序） | 12% (6/51) | 22% (11/51) | 24% (12/51) |
| 只用新 FoM | 16% (8/51) | 20% (10/51) | 29% (15/51) |
| **新（混合 0.3/0.7）** | **14% (7/51)** | **25% (13/51)** | **27% (14/51)** |

- **内置 118 物相库**：13 试样排序**无回归**（唯一变化：Boehmite 23→22）
- 若把预筛池放大到 200，混合口径可达 **Top-1 16% / Top-5 27% / Top-10 29%**
  （未改默认池，以控制单次识别耗时在 1.5–3 s）

## 三、仍未解决的问题（诚实汇报）

**COD 检索召回才是当前最大瓶颈**，而不是排序。13 试样中 α-石英、MgCO₃、白云石、
白云母、高岭土、钙长石等经常落在预筛池 100 名之外（诊断脚本显示部分真物相在池内排到
150+ 名）。继续调排序收益有限；下一步应优化 `search_cod_by_d_peaks` 的召回
（如放宽 d 容差 0.02 → 0.03、提高 `max_ref_peaks`、或对主峰做强度加权召回）。
