## 四、B 组：算法改进

B 组按"杠杆值"排序实施，三项相互独立但都作用于检索排序链路。

### 4.1 B-3：局部噪声自适应幅度阈值

**问题**：原 FoM 特异性项用**全局阈值**过滤噪声峰，但 13 试样的实测谱噪声分布不均（5-1 / 7-2 等多相试样的低 2θ 段噪声高，高角度段接近基线），全局阈值在"噪声区"放过假峰、在"安静区"误杀弱真峰。

**方案**：用**局部 MAD（中位数绝对偏差）× k** 作为每峰阈值，窗口默认 5°，k=3.0。

**实现**：

- [foam.py](file:///d:/Project/XRD/PolyXRD/src/polyxrd/services/foam.py) 新增 `local_mad_threshold(obs_two_theta, obs_intensity, window_deg=5.0, k=3.0, min_count=3) -> np.ndarray`：
  - 全局 MAD 兜底：当窗口内峰数 < `min_count` 时退回全局阈值；
  - 用 `np.searchsorted` 在已排序 2θ 数组上滑窗，复杂度 O(n log n)；
  - 每峰返回独立阈值 `σ_local = 1.4826 × MAD_local × k`。
- `compute_fom` 加 `obs_noise_floor=None` 参数：传入时特异性项的 `sig_mask = obs_int >= obs_noise_floor`，未解释强度与总强度都改为"显著峰"口径；
- 同步修了 `np.sum(generator)` DeprecationWarning → Python `sum` 内建。

**测试**：[tests/test_fom_local_mad_filter.py](file:///d:/Project/XRD/PolyXRD/tests/test_fom_local_mad_filter.py) 10 个用例（空输入 / 退化为全局 MAD / 纯噪声块 / 输入顺序保持 / `compute_fom` 集成 / None 等价 noop / 强未解释峰仍惩罚 / 特异性用显著峰 / 长度不匹配兜底），全部通过。

**基准收益**（13 试样，`bench_search_match.py`；基线 = 已提交 HEAD）：

| 指标 | 基线 (HEAD) | + B-3 only | 变化 |
|---|---|---|---|
| A 级 top10 / MISS | 45/49 (92%) / 0 | 45/49 (92%) / 0 | 持平 |
| B 级 MISS | 4 | 4 | 持平 |
| B 级 top10 | 42/49 (86%) | 43/49 (88%) | **+1** |

> ⚠️ **复核结论（2026-09-30）**：B-3 单独启用净收益仅 B 级 top10 +1、MISS 零改变，
> 却带来 7-2 Clinochlore（A 5→7 / B 12→16）、5-1 Cristobalite（B 11→12）退化；

### 4.2 B-4：PO（择优取向）感知检索评分

**问题**：B 级 4 个 MISS 中，Muscovite（267 参考峰）、Clinochlore（≈90）、Hornblende（211）均为择优取向敏感相。FoM 假定强度各向同性，强峰被择优取向压低时漏检，FoM 偏高、排名掉到 top14 之外。

**方案**：在检索阶段对**密集参考峰**相加 March-Dollase 网格搜索，把最优 r 的 FoM 作为该相最终分。

**March-Dollase 修正**：`G(α) = (r²·cos²α + (1/r)·sin²α)^(−3/2)`，其中 α 为散射矢量与择优轴夹角。

**实现**（[phase_identifier.py](file:///d:/Project/XRD/PolyXRD/src/polyxrd/services/phase_identifier.py)）：

- 常量（**定稿值**，初版括号内为扫参前）：
  ```python
  _FOM_PO_GRID = (0.6, 0.8, 1.0, 1.3)
  _FOM_PO_AXIS = (0, 0, 1)
  _FOM_PO_MIN_REFS = 80       # 初版 50 → 定稿 80 (只对极密集峰表相启用)
  _FOM_PO_IMPROVE_FRAC = 0.10 # 初版 0.05 → 定稿 0.10 (>10% 实质改善才采用)
  ```
- `_match_phase_fom` 加 `po_grid` / `po_axis` 参数；当 `total_ref_peaks >= 80` 且 hkl 齐全时，先算 `fom_base (r=1.0)`，再扫 `r ∈ po_grid`，**仅当 `fom_r.score < best_fom.score × (1 − 0.10)` 时才采用 r≠1.0 的结果**；
- `identify_with_element_filter` 默认开启 B-4。
- 同步修了 [rietveld_refiner.py](file:///d:/Project/XRD/PolyXRD/src/polyxrd/services/rietveld_refiner.py) 的 `_hkl_angle`：六方/三方四指标 (h,k,i,l) 自动截前 3 维 (h,k,l)，与既有 `rietveld_refiner.py:1077-1082` 处理一致，避免 `(4,) dot (3,)` 维度不匹配。

**两道护栏的设计动机**（定稿值经 13 试样扫参标定）：

1. `total_ref_peaks >= 80`（初版 50，定稿收紧）：只对极密集峰表相（Muscovite 267 / Hornblende 211）启用 March-Dollase。放宽到 30 会让 7-2 Clinochlore 等中等密度相被 r 网格误优化（B top3 −2 / MRR_B −0.026），收紧到 150 则少收 5-2b Muscovite；实测 80~100 为平台，取 80；
2. `_FOM_PO_IMPROVE_FRAC = 0.10`（初版 0.05，定稿提高）：r≠1.0 须比 r=1.0 好 >10% 才采用。0.05 会放行大量"轻微虚假优化"的伪匹配候选挤掉真相（5-2b Muscovite 仍 MISS），0.10 只接受实质改善。

**基准收益**（13 试样；基线 = 已提交 HEAD）：

| 指标 | 基线 (HEAD) | 本轮定稿 (B-4 独用) | 变化 |
|---|---|---|---|
| A 级 MISS | 0 | 0 | 持平（A 级 MISS 本就为 0） |
| A 级 top10 | 45/49 (92%) | **47/49 (96%)** | **+2** |
| B 级 MISS | 4 | **2** | **4→2 ✓** |
| B 级 top3 | 31/49 (63%) | 33/49 (67%) | +2 |
| B 级 top10 | 42/49 (86%) | 42/49 (86%) | 持平 |
| MRR (A / B) | 0.491 / 0.478 | **0.498 / 0.487** | ↑ |

**回收的 2 个 B 级 MISS**：5-2 Muscovite（B MISS→13）、5-2b Muscovite（B MISS→19）；A 级 side 5-2 Muscovite 11→6、5-2b Muscovite 11→7。B 级遗留 2 个 MISS：Hornblende 7-2（211 峰已过护栏但仍未召回）、Zircon 7-2（参考峰仅 17，PO 护栏排除）。

### 4.3 B-5：PFSM 接入排序链路（实测后默认禁用）

**问题**：5-1 Cristobalite（71 条参考峰，弱线多）在 B 级排 14，被 `top_n=12` 截断 → 组合选择时缺失。FoM 基于峰位一一匹配，弱线漏检时分数偏高；PFSM（profile fitting score）直接比实测谱与单相合成谱的形态相关性，对弱线多的相更稳健。

**方案**：FoM 排序后对 top-N 候选算 PFSM corr，按 `(1-w)·FoM_rank + w·PFSM_rank` 重排。

**实现**（[phase_identifier.py](file:///d:/Project/XRD/PolyXRD/src/polyxrd/services/phase_identifier.py)）：

- 常量：`_FOM_PFSM_TOP_N = 50`，`_FOM_PFSM_WEIGHT = 0.2`（实测后改为 `0.0`）；
- 复用 `foam.profile_fitting_score` 计算 Pearson 相关；
- 在 `identify_with_element_filter` 末尾对 top50 重排，rank 算法：按 corr 降序排得到 `pfsm_ranks[i]`，与 `fom_ranks[i]` 加权后升序重排。

**实测结果（w=0.2，4 试样子集）**：

| 试样 / 相 | 定稿(B-4) 排名 | + B-5 (w=0.2) 排名 | 评估 |
|---|---|---|---|
| 5-1 Cristobalite | 14 (B级) | 11 (B级) | 进 top12 ✓ |
| 5-2b Muscovite | 10 | **19** | 接近 MISS ✗ |
| 3-1 Corundum | 2 | **6** | 跌出 top3 ✗ |
| 3-1 Fluorite | 3 | **7** | 跌出 top3 ✗ |

**关键判断**：B-5 在 w=0.2 时虽然让 5-1 Cristobalite 进 top12，但 `build_refinement_combination` **仍选 Zircon 而非 Cristobalite**——5-1 组合缺失的真问题在组合选择策略（Cristobalite 与 Zircon 都含 Si，组合算法选了 ZrSiO4），不在搜索截断。同时 B-5 退化 3-1（Corundum/Fluorite 跌出 top3）与 5-2b（Muscovite 接近 MISS，B-4 的成果被抵消）。

**决策**：默认禁用 B-5（`_FOM_PFSM_WEIGHT = 0.0`），参数保留供按需启用。注释记录实测结论：

```python
# 实测: w=0.2 在 5-1 让 Cristobalite 排 14→11 (进 top12), 但组合算法仍选
# Zircon 而非 Cristobalite → B-5 未能解决 5-1 组合缺失; 同时退化 3-1
# (Corundum 2→6, Fluorite 3→7) 与 5-2b (Muscovite 10→19). 5-1 的真问题在
# build_refinement_combination 的选择策略, 非搜索截断. 故默认关闭, 留参数供按需开启.
_FOM_PFSM_WEIGHT = 0.0
```

禁用后基准恢复到定稿（B-4 独用）水平：A 级 MISS 0、B 级 MISS 2、B 级 top10 42/49 (86%)、B 级 top3 33/49 (67%)、MRR_A 0.498 / MRR_B 0.487。
