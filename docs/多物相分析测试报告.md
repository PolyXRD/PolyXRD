## 一、测试目的

验证 PolyXRD 软件多物相分析功能在实际衍射数据上的表现,同时验证 COD 离线数据库在多物相识别中的可用性与完整性。

### 验证目标

1. **多物相分析算法**:残差剥离法 + 主峰匹配(main_peak_match)+ 强度加权召回率(intensity_weighted_top_recall)能否正确识别混合样品中的多个物相
2. **COD 数据库完整性**:71199 物相库是否覆盖常见矿物(TiO2、SiO2、CaCO3、Fe2O3 等),d-I 峰数据是否准确
3. **元素过滤(EDX)**:基于 EDX 元素信息的候选物相过滤能否有效排除干扰物相
4. **未解释峰软屏蔽**:对数据库外物相(如 K-mica)主峰的屏蔽机制是否有效

## 五、5-2 问题详细诊断

### 5.1 诊断方法

使用 [diagnose_5_2_fe_caco3.py](file:///d:/TraeSolo/PolyXRD/scripts/diagnose_5_2_fe_caco3.py) 和 [debug_5_2_candidates.py](file:///d:/TraeSolo/PolyXRD/scripts/debug_5_2_candidates.py) 进行独立诊断:

1. **特征峰单独搜索**:用 Fe2O3 / CaCO3 / K-mica 的特征 d 峰单独搜索数据库
2. **候选分析**:检查完整 30 峰搜索时这些物相是否进入 top-200 候选
3. **元素过滤验证**:检查 EDX 过滤是否会错误排除目标物相

### 5.2 诊断结果

#### 5.2.1 Fe2O3(赤铁矿)— 数据库存在,特征峰搜索完美匹配

用 8 个 Fe2O3 特征峰(d=2.6947, 2.5130, 1.6938, 1.4857, 1.4532, 2.2796, 3.6718, 1.8399)搜索:

```
97-1546383     Fe2 O3     R -3 c      1.00 100.0%  95.4%  87.5%  ✓
97-2101167     Fe2 O3     R -3 c      1.00 100.0%  95.4%  87.5%  ✓
... (共 15+ 个 Fe2O3 物相,top_p=100%, iw_tr=95.4%, EDX 通过)
```

**结论**: Fe2O3 在数据库中存在且数据准确,用特征峰搜索时 100% 匹配。问题在于完整 30 峰搜索时被其他 top_p=100% 的杂元素物相挤掉。

#### 5.2.2 CaCO3(方解石)— 数据库存在,主峰与样品匹配

样品 CaCO3 主峰 d=3.0275,数据库中 CaCO3(R -3 c)主峰:

| 97-9009667 | C Ca O3 | R -3 c | 3.03 | ✅ d=3.0275 |

**结论**: CaCO3 在数据库中存在,主峰与样品完全匹配(±0.03 Å)。

#### 5.2.3 K-mica(白云母)— 数据库存在相似物相

通过化学式搜索(K + Al + Si),找到 muscovite 2M1 相似物相:

```
97-9004246  f=Al K O8 Si3   SG=C 1 2/m 1   top_p=80% iw_tr=31.3% EDX=✓
97-1011187  f=Al K O8 Si3   SG=C 1 2/m 1
97-9000858  f=Al K0.25 Na0.75 O8 Si3  SG=C 1 2/m 1  (K-Na 替代)
```

**结论**: K-mica 相似物相(Al K O8 Si3,C 1 2/m 1)存在,但化学式无 H(数据库可能省略 H)。这些物相在 5-2 完整搜索中不在 top-25 候选,被 top_p=100% 的杂元素物相挤掉。

### 5.3 根本原因分析

#### 5.3.1 Round 3 误匹配 Ca3O7Si2(wollastonite-like)

5-2 在 Round 3 时,剩余峰的最强峰可能是 d=3.0275(CaCO3 104)或 d=2.6947(Fe2O3 104)。算法选择了 `97-9012094 f=Ca3 O7 Si2 SG=P 1 21/a 1`(top_p=80%, mpm=1, iw_tr=46%),而非 CaCO3。

**原因**:
- Ca3O7Si2 主峰也接近 d=3.0,与样品 d=3.0275 匹配,mpm=1
- Ca3O7Si2 的 top_p=80% 与 CaCO3 相近,但 iw_tr=46% 可能高于 CaCO3(因 Ca3O7Si2 峰更密集,覆盖更多测量峰)
- EDX 过滤无法区分(Ca 在 EDX 中,C 和 O 是 light element)

#### 5.3.2 K-mica 主峰干扰(已缓解)

5-2 样品最强峰 d=9.9057(K-mica 001)在数据库中无对应物相。测试脚本已实现预过滤(d > 5.5 Å 排除)和未解释峰软屏蔽,但 K-mica 的 d=4.9679(002)仍在搜索范围内,可能干扰排序。

#### 5.3.3 算法对化学计量比相近物相的区分度不足

Ca3O7Si2(Ca:Si:O = 3:2:7)与 CaCO3(Ca:C:O = 1:1:3)的元素组成差异在 EDX 层面无法区分(都含 Ca,O 为 light element)。当前算法依赖 d 峰匹配排序,但两者主峰相近时无法正确区分。

### 5.4 数据库完整性结论

**5-2 未匹配的 3 个物相均存在于 COD 数据库中**,且用特征峰单独搜索时匹配度极高(Fe2O3: 100%, CaCO3: 100%, K-mica 相似物相: 80%)。**数据库完整,问题在算法对复杂混合样品的排序与干扰物相处理**。

## 六、后续优化方案

### 6.1 短期优化(算法改进,不改数据库)

#### 6.1.1 引入化学计量比约束

**问题**: Ca3O7Si2 误匹配 CaCO3,两者含 Ca 且主峰相近。

**方案**: 在候选排序中加入化学计量比匹配分。对于每个候选物相,解析其化学式为元素-计数字典,归一化后与"未被解释的测量峰对应的元素组合"比对。

```python
def stoichiometry_score(phase_formula, edx_elements, explained_peak_d):
    """化学计量比匹配分:物相元素是否与 EDX + 残余峰一致"""
    counts = parse_counts(phase_formula)
    # 归一化(最大元素=1.0)
    n = normalize_counts(counts)
    # 主元素(归一化后=1.0)必须在 EDX 中
    main_elem = max(n, key=n.get)
    if main_elem not in edx_elements:
        return 0.0
    # 次元素比例合理(如 CaCO3 的 Ca:1, C:1, O:3)
    # Ca3O7Si2 的 Ca:1, Si:0.67 — 若 EDX 无 Si 则扣分
    ...
```

**预期效果**: Ca3O7Si2(含 Si)在 CaCO3(不含 Si)场景下得分降低,CaCO3 优先匹配。

#### 6.1.2 RIR(参比强度)加权

**问题**: 当前质量分数计算仅用"被解释测量峰强度之和",对峰密集物相有利。

**方案**: 引入 RIR(Reference Intensity Ratio,刚玉参比强度),从 COD CIF 文件提取或计算各物相的 RIR 值,用于校正质量分数:

```
wt_i = (I_i / RIR_i) / Σ(I_j / RIR_j)
```

**预期效果**: Ca3O7Si2(RIR≈0.5)与 CaCO3(RIR≈3.0)的质量分数校正后差异更明显,有助于区分。

#### 6.1.3 候选去重(同结构不同化学式)

**问题**: top-25 候选中有大量同结构不同化学式的物相(如 15+ 个 Fe2O3, R -3 c),占据候选位置。

**方案**: 对候选物相按(化学式归一化 + 空间群)分组,每组只保留 top_p/iw_tr 最高的代表。

```python
def dedup_candidates(candidates):
    """同化学式+空间群的物相只保留最优代表"""
    groups = {}
    for c in candidates:
        key = (normalize_formula(c["formula"]), c["space_group"][:6])
        if key not in groups or c["score"] > groups[key]["score"]:
            groups[key] = c
    return list(groups.values())
```

**预期效果**: 候选列表更精简,CaCO3/Fe2O3/K-mica 更容易进入 top-25。

### 6.2 中期优化(数据库扩展)

#### 6.2.1 补充 K-mica 等层状硅酸盐

**问题**: 5-2 的 K-mica(白云母,KAl3Si3O10(OH)2)在 COD 数据库中无完全匹配物相,仅有 Al K O8 Si3(C 1 2/m 1)相似物相(缺 H)。

**方案**: 从 COD 官网下载白云母、伊利石、蒙脱石等层状硅酸盐的 CIF 文件,补充到 PolyXRD 数据库。

**目标 COD ID**(待验证):
- 1000040, 9004196-9004198(muscovite 2M1)
- 9012601, 8100308(相关多型)

#### 6.2.2 补充 ZnO

**问题**: ZnO(P 63/m m c)在 COD 数据库中缺失,导致 2-1/3-1/3-2/4-1 样品无法测试。

**方案**: 从 COD 下载 ZnO 标准品 CIF(如 9007585, 1011146),补充到数据库。

### 6.3 长期优化(算法架构)

#### 6.3.1 Rietveld 精修集成

**目标**: 对多物相分析结果进行 Rietveld 精修,获得精确的质量分数和晶胞参数。

**方案**:
1. 多物相分析输出候选物相列表 + 初始质量分数
2. 从 COD 下载对应 CIF 文件作为初始结构模型
3. 调用 GSAS-II / FullProf 进行 Rietveld 精修
4. 精修后的质量分数反馈到物相分析,迭代优化

#### 6.3.2 全谱拟合替代峰匹配

**问题**: 当前基于 d 峰匹配,对峰重叠严重的样品区分度不足。

**方案**: 引入全谱拟合(Pawley / Le Bail),用整个衍射图谱与数据库物相的理论图谱比对,提高区分度。
