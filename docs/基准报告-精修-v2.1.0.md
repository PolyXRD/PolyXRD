## 三、口径与限制（如实说明）

- wR 为**加权**口径（`stat_weights=poisson`）；单位权下 Rexp/GOF 不可解读。
- Bragg R 为 v2.1-D 新指标（按反射积分强度对账）；0 = 未取得（旧结果/提取失败）。
- 定量口径 relative = 部分相未匹配到结构（降级原因见诊断 `diag.weight_basis_relative`）。
- 3-2 含 29.47% 非晶玻璃：模型无法表示非晶相，其 wR 仅供参考、不参与定量。
- 微量相（如 3-1 的 CaF2 = 1.36%）受检出与权重限制，绝对偏差天然偏大。
- 5-x / 7-2 的真值只给相名不给 wt% → 不含定量对比。
